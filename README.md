# Quotes Listing Application

A tiny frontend app that displays a list of quotes.

## Files
- index.html — main HTML page
- script.js — application JavaScript
- style.css — styles

## Usage
1. Open `index.html` in your web browser.
2. The app will load and display the list of quotes.

For development, you can use a simple static server (e.g., VS Code Live Server extension) or open the file directly.

## Notes
- No build step required — plain HTML/CSS/JS.
- Edit `script.js` to change or extend the quotes and behavior.

If you want, I can also add a short example, screenshots, or instructions to run with Live Server.
